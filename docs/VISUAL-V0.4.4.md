# v0.4.4：驾驶姿态与脚底接地

延续 v0.4.3 的鸟首顶棚、开放驾驶舱和上下工具结构。这轮优先修正人体与机器的连接关系，保留游戏原生角色、像素密度和环境光照。

## 实现

- Champion / Avian 两款机体使用实际角色的上臂、前臂、手与服装精灵副本，组成伸向控制台的坐姿；面部继续使用原角色。只创建渲染器，不复制身体物理、物品或脚本。
- 缺失的肢体及其下游不显示；角色原始肢体位置不受视觉求解影响。
- 双腿增加纯数值两骨骼求解；站立和行走时向地面探测，脚掌对齐可达接触点，空中保持原有收腿姿态。不可达位置限制骨长，不拉伸精灵。
- 扩宽腿甲，暖色装甲与鸟人机身统一。步频随速度调整，减轻滑步观感。
- 装配界面测试在预览稳定后截图；测试探针新增接地、手数、缺手恢复观测，不进入玩家包。

## 视觉判断与边界

本轮检查装配预览、左右行走、站姿截图；脸部窗口、座舱和工具轮廓可区分。暗洞中按游戏光照变暗，没有给机甲强制全亮材质。
平地接地观测通过，不代表任意台阶、斜坡和窄角都通过；这是外观求解，不改变碰撞与移动能力。
角色体型/服装矩阵、多人、多 Mod、长期性能对照均未完成。没有用短窗口帧时间冒充完整性能基准。
