# v0.4.8 空投与召唤器说明

使用信标或默认 G 请求部署，等待 1.2 秒后机甲从选定落点上方下降。机体折腿、收拢工具臂，接近地面时喷气减速。检测到真实地面接触后开始 0.55 秒的着地展开，完成后才能登机和装配。上方空间由机体体积扫掠检查，洞顶限制空投高度。再次请求可取消部署，停放的空机回收前有 0.3 秒收拢动作。

驾驶与待机时的右上角操作框、登机操作弹窗、获赠信标时的按键教学及装配面板顶部快捷键教学均已移除。操作说明集中在中英文信标物品描述中。P 打开的装配界面提供换件、配色、预览、应用和取消。交互失败还能得到一次原因提示。

参考本机 Starbound 的 `vehicles/modularmech/modularmech.lua`、`.vehicle` 与 `.animation`。原作部署段 1.2 秒，初速 -20，助推段 0.8 秒。启停过渡为 3 帧、0.3 秒。Wayfarer 的发信等待、按地形净空计算下落高度和关节插值适配了本游戏。当前实现覆盖空投和着地变形，导弹、地雷、无人机和护盾的独立行为、能量与防护机制仍有移植工作。
