## 3. A1：长按跳跃键持续喷气

### 玩家体验

1. 地面短按仍正常跳跃；持续按住约 0.18 秒开始喷气。
2. 空中重新按住跳跃键也可启动喷气，允许走下平台后自救。不限制只能在起跳那一次按键后使用。
3. 持续按住持续上升，可左右操纵；松开结束推力，自然下落。不增加燃料或过热。
4. 喷气火焰/声音/提示与真实推力状态一致。碰顶不穿墙，也不积蓄突然弹飞的速度。
5. 菜单、暂停、输入框、失焦、下机和切场景立即取消喷气；恢复后要求松开再按，避免菜单中按住空格导致恢复时乱飞。

### 建议起始参数（必须实机调，不是已验证结论）

| 参数 | 初值 |
|---|---:|
| 起跳速度 | 26 |
| 长按阈值 | 0.18 秒游戏活动时间 |
| 喷气净向上加速度 | 35 世界单位/秒² |
| 最大上升速度 | 26 世界单位/秒 |
| 最大下落速度 | 40 世界单位/秒 |
| 燃料 | 不限 |

`Update` 采样输入并维护按键边沿、持有时长和门禁；`FixedUpdate` 修改速度。不要在每帧重复赋起跳速度。集中提供有合理范围的 BepInEx 配置，避免魔数散落。

当前 Rigidbody2D.mass=60。若使用 AddForce，必须按质量换算；直接加 90 力并不能抵消当前重力。可在物理步按加速度更新竖直速度，补偿 `Physics2D.gravity.y * rb.gravityScale`，使启用喷气后的净加速度等于配置值；封顶上升速度。不修改全局重力，不依赖固定帧率。

用接触法线或短上方探测识别顶碰，停止朝顶面的推进和速度积累；离开顶面后能继续飞。分别覆盖起跳、空中长按、下坠制动、贴墙上升、矮顶和斜面。复用输入门禁并补充 `Application.isFocused`，不要绕过暂停补丁。

### 飞行新增的退出/存档风险

目前 SaveGame 前会强制下机并销毁机甲；不会持久化部署实体。长距离飞行后照搬此逻辑，可能把裸露玩家保存到高空。必须单列处理，不能只测地面存档。

本轮优先保持“保存回收、读档后重新召唤”的既有契约。实现可验证的安全退出点：记录本场景最近一个有地面支撑、角色净空足够的安全站位，退出时重新检查地形，不能使用已经被挖空的缓存；优先使用当前附近安全点，必要时回退到仍有效的最近安全点并提示玩家。记录必须在换世界/换层时清空，不能跨场景传送。主动空中 F 下机在没有安全点时拒绝并提示先降落。

保存、死亡/换层等强制生命周期不能简单取消原版保存，也不能在同步 SaveGame Prefix 中等待数秒降落。如果确实找不到任何有效安全点，接手者需要实现并测试最小的随存档驾驶恢复状态（核对 CUCoreLib save provider、带 schemaVersion），或另一个能证明读档安全的回退方案。**这是明确的风险门禁，不允许用“保存成功”掩盖读档坠死；不得直接宣称这一项已解决。** 若必须扩展持久化，单独记录实现和迁移成本，不顺带改成全世界永久机甲系统。

## 4. A2：钻头强化与可通行刷形

先修截面，再增伤。保留原生 `DamageBlock`、掉落和保护边界；不以直接清空地图格子代替伤害流程。

建议初值：脉冲间隔 0.10 秒、每格伤害 2400、每列最多向内推进 2 格、每脉冲最多处理 24 个唯一格子。有效钻探最远距离初设为从机体中心 10 世界单位，代码和配置说明必须统一这一测量原点。武器实际起点使用钻头尖端；不可击中机体背后的方块。

刷形按机体包围盒在挖掘方向垂线上的投影确定，给 0.5 世界单位单侧余量。若单位垂线为 p，横截面半宽为：

```text
abs(p.x) * Size.x / 2 + abs(p.y) * Size.y / 2 + 0.5
```

当前尺寸下，水平挖通道需要约 7.6 单位高度，向上挖需要约 5.2 单位宽度。转换成格子时向外取整，并覆盖格心偏移；不能机械取“左右各一格”。本机参考中 1 格约 1 世界单位，仍须核对实际转换函数。

实现要求：

- 每个截面列从近到远寻找首个可见实体表面，只允许有限厚度推进，不能隔着坚固墙伤害后方建筑或动物。
- 越界过滤、格子去重、最近优先、每脉冲上限；低帧率不补发一长串过期脉冲。避免每帧分配临时集合、反射和全图扫描。
- 地形伤害与动物/建筑伤害分开配置。本次加强采矿不能意外把战斗伤害同步放大十几倍。
- 保留 `cantHit` 等现有保护语义、边界检查与原版掉落。特效和音效限频，避免每格都爆一套昂贵效果。
- 把纯刷形计算抽成可测试函数：水平/竖直/斜向、格边界、去重、最大预算、越界和近远排序。不要为了架构拆成多个无必要工程。
- 新增实际破坏方块数、每脉冲候选/处理数、耗时观测；不要把现有 `DrillHits` 重命名后冒充破坏量。

体验目标：普通软岩一轮破坏；本机 5000 硬度目标约 0.4 秒内，15000 约 1 秒内（从首次有效脉冲计）；机甲可连续驶入自己挖出的水平和向上通道。数值是调参目标，最终报告实际测量和材料 ID，不猜测玩家看见的岩石类别。

## 5. B：重做外观与动画

### 美术方向

补充素材调研见 [Pixel Art Atlas 1.4M](PIXEL-ART-ATLAS-RESEARCH.md)：E 盘已有约 30 MB 样本和 76 张机械类预览。适合作为图标/零件参考；不直接代替侧视分层机体和动画。使用前查该文的来源、许可说明与尺寸限制。

“废旧工业救援/采矿机甲”：偏侧视，厚重驾驶舱、能看懂的髋膝踝结构、前后腿错位；一侧钻头、另一侧炮，背部有可辨识的喷口。低饱和灰钢/灰橄榄为主，局部锈褐或警示黄；舱窗改成小面积暗玻璃和亮缝，减少青色大灯箱感。

本地参考：`D:\testGround\casualties-mecha-mod\docs\art-style-spec.md`；原版素材观察目录 `D:\testGround\_casualties-analysis\reference-art`。它们可帮助理解金属装备材质、像素密度与边缘，不能把原版提取素材打进包。不要把“游戏像素风”误解为只用三种平涂颜色：装备可以有多阶明暗、冷暖偏移、磨损和选择性轮廓。颜色数量不是硬性考核。

先制作一张**实际游戏截图中的合成预览**，以玩家、岩壁、原版装备为比例参照，同时展示左右朝向和暗处效果；只在纯白背景好看不算通过。定下比例和材质，再拆资产并接动画。

### 资产与装配

- 使用原创透明 PNG 和可编辑源文件，按部件组织在 `src/WayfarerMech/Assets/`；项目文件显式嵌入或建立有清单的资源加载。
- 初始按 PPU=8、Point 过滤、Clamp 采样。可先以总高约 56–64 像素设计，碰撞核心仍保持 4.2×6.6 世界单位；装饰溢出需克制。精确尺寸由游戏画面验证，不能只把图片放大。
- 建议分层：躯干、舱窗、髋部、前后大腿/小腿/脚、钻头、炮、背部喷口、火焰和信标。数量服务动作，不为凑部件数拆碎。
- 明确每部件 pivot、连接点、钻尖/炮口/喷口位置、前后 sortingOrder；统一像素坐标与世界坐标转换。
- 用独立 `MechVisual` 或等效小组件管理外观。左右翻转只影响视觉根，不能把 Rigidbody 或 Collider 一并负缩放；转向时前后肢体层级应一致。
- 从各武器自己的 pivot 指向鼠标，校准实际发射/钻探起点；左瞄不能上下颠倒炮身。武器外观、射线和命中位置一致。
- 若使用生成图像，按 imagegen skill 工作；生成概念图只是参考，必须整理为尺寸准确、透明干净、可装配的像素资产，不能把整张高分辨率概念图直接贴进游戏。
- 纹理和 Sprite 缓存复用并正确释放，不能每帧生成贴图。保存原创资源来源说明。

### 最小动画集

| 状态 | 必需表现 |
|---|---|
| 待机 | 重心稳定、小幅机械活动，别让整机像果冻 |
| 行走 | 两腿相位错开，膝踝可读，脚底滑动受控；速度跟随实际 vx |
| 钻探 | 钻头旋转/循环帧与接触反馈；空转与挖中有区别 |
| 射击 | 炮口闪光和短后坐，实际命中不随视觉偏移 |
| 喷气 | 真实 thrust 状态驱动火焰，空中收腿、机身姿态小幅变化 |
| 落地 | 短促压缩恢复，不能改变实际碰撞大小 |

避免直接沿用整条腿的正弦摆动作为最终动画。若连续旋转造成像素闪烁，尝试有限角度帧或离散视觉角度；不得通过量化物理位置来修美术抖动。

HUD 一并整理：字号和中文可读、不盖关键原生状态栏，提示读取真实绑定；保留简洁的“喷气中/驾驶中”反馈，不加入调试面板。

## 8. 验收矩阵与证据

每个案例记录 DLL 哈希、场景、输入、前后状态、截图/录像和结论。只允许 PASS / FAIL / NOT_RUN / BLOCKED；直接调用内部方法不能替代真实键鼠入口。

| 案例 | 必须观察的结果 |
|---|---|
| 起跳/持续飞行 | 空旷竖井短按与长按对比；持续按 3 秒有持续上升，初步目标净上升至少 45 单位；松开停止推力 |
