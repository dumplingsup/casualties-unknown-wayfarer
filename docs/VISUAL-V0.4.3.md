# v0.4.3：鸟首驾驶舱结构版

根据本会话生成的侧视概念图，重画默认 Champion 和 Avian 系列驾驶舱。
不是把概念图缩小塞进游戏：保留原生像素密度、可动画部件和真实角色显示。

## 这轮改动

- 鸟首变成横跨座椅的顶棚，钩状鸟喙位于操作台前方；后方羽片连接承重立柱。
- 机体改为容纳驾驶员的舱体：靠背、座垫、仪表屏、双操纵杆、前护栏及下部承重梁。
- 驾驶员在鸟人舱中进一步下移 5 原生像素；面部窗口保留透明，头/眼/上躯干仍来自当前角色。
- 鸟人机体远侧工具挂点提高并前移，形成上层机炮、下层钻头，减少侧视时相互遮挡。
- 钻头从 14×20 扩到 20×20，改用钢灰色；钻尖位置按实际图片宽度和 pivot 计算，保留工具定义的尖端坐标。
- 物品图标由前后层合成，能看到顶棚和羽片，不再只显示腹部装甲。

角色操作杆目前是舱内结构图形，尚未实现真实双手握杆的 IK/动画。
腿部沿用 v0.4.2，本轮主要重做上身、驾驶关系和工具布置，没有把所有种族都改成鸟首。

## 结构契约

鸟人机体画布 76×64、pivot (32,34)、PPU=11；头部中心约 (30,24)、近臂 (46,48)、髋 (24/40,60)。
前层脸部保留区 (24,17)–(42,30) 由测试检查。不同角色头型仍需扩展实机矩阵。
工具挂点改变仅用于 Champion / sb_avian / sb_avianproto；插件 GUID、装配 ID、碰撞体及伤害配置不变。
顶棚/鸟喙有视觉悬挑，极窄处仍可能比碰撞体先碰到墙面，未宣称精灵轮廓等同碰撞轮廓。
