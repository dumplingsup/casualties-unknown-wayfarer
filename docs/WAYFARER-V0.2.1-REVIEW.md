# Wayfarer v0.2.1：机体结构审查与外观候选版

日期：2026-11-10。基于 v0.2.0（DLL `7761b8d4…6463fe`）。本轮重点是结构设计和装配一致性，不是把 v0.2 报告中的所有未完成项一起标成已修复。

## 为什么 v0.2 的机体看起来不合理

查看了源 PNG、装配预览、`runs/v02-smoke4/shot-board.png` 和 `runs/v02-final10/shot-materials.png`，并核对 MechVisual/MechController：

1. **驾驶舱身份不清**：原舱体有眉甲、下颌、面部通风口，放在胸前偏高位置，很像机器人头盔。没有清楚的舱门和乘员空间，因此难以读成可坐进去的载具。
2. **武器抢占轮廓**：原炮长 38 px、钻臂加钻头横向延伸很大。近侧钻尖水平位于根部前约 52 px，碰撞体半宽却只有 16.8 px，造成工具深入墙壁而身体离墙很远的感觉。
3. **承重结构弱**：上半身占据大面积，腿部关节与脚底定位不够协调，缺少驾驶舱→底盘→髋→腿→地面的清晰连接关系。
4. **安装位置不可信**：肩炮缺少固定支座；火焰使用的偏移没有对齐背包贴图实际喷口。看起来像独立零件粘在一起。
5. **噪点多于形体**：材质细节已有，但在实际游戏尺寸和昏暗环境下，轮廓、窗、关节的主次还不清楚。增加锈点或颜色数量不会自动提升协调性。
6. **预览本身会误导**：旧脚本的像素旋转方向与 Unity 的正角度相反；钻头位置没有跟随父级钻臂旋转；6 倍图先放大部件再旋转，和原生像素装配后放大的结果不同。

这些是实际资产/代码问题，不是需要下载更多素材才能解决的问题。Atlas 仍只作为细节参考，本轮没有复制其中像素。

## 本轮已经实施

- 新绘制中央一体舱：竖向侧窗、舱门、踏步与下部支撑；取消像头部一样独立点头的动画。
- 躯干改成驾驶舱周围的设备舱与承重底框，缩小横向轮廓，减少新部件的随机磨损噪点。
- 肩炮从 38×12 改为 26×10 原生像素，加固定炮座；钻臂从 34×16 改为 24×14，钻头从 20×12 改为 14×12。
- 钻尖水平偏移从约 52 px 缩至 37 px，仍保留工具突出身体的合理空间；炮口/钻尖锚点同步更新，不只替换贴图。
- 双腿采用轻微反曲的静态承重姿态，统一髋高度，脚底更接近实际碰撞体底边；没有缩小碰撞体来伪装通行能力。
- 背包靠近机身，喷焰接到贴图里的两个喷口。
- 新增 `MechRig.cs` 作为装配尺寸源，预览读取同一份数值；修正预览旋转方向及钻头父子变换，先原生尺寸装配再最近邻放大。
- 增加左右、上下瞄准、喷气姿态、碰撞框/关节离线矩阵。喷气图是静态姿态示意，不是实机动态帧或物理验收。
- 修正一个误导性提示：强制退出未找到安全点时不再显示“已转移到安全地面”。**没有因此解决 unsafe-current 兜底风险。**

本轮不改喷气数值、挖掘伤害/预算、碰撞体尺寸、召唤算法、炮弹目标过滤或存档格式。

## 接下来真正值得优化的事项

按优先级处理，不要用更多美术细节掩盖玩法缺口：

1. **战斗目标**：现有 `ignoreBody=true` 意味着炮不能攻击 Body 角色。用户原始需求包含战斗，这仍未完整兑现。需要区分敌人、乘员、自身与友军，再做真实受伤观察，不能只把该参数改成 false 就发布。
2. **无安全点强制退出**：当前最后仍回退到机体当前位置。缓存地面验证成功一次不等于所有高空保存都安全。单独测缓存被挖掉、换层、死亡等情况。
3. **顶碰判断**：当前混合多种范围探测，包含高达 1.7 单位的预判距离和未按法线筛选的高处接触点；容易把侧墙/临近地形当顶棚。应收敛成实际接触法线与短距离 hull cast，并统一物理状态、HUD、喷焰的状态来源。需要角落和横移离顶测试，不在未实测时贸然替换。
4. **近距离瞄准与工具穿插**：现在模型比原版紧凑，但向下/向上极限瞄准仍需检查武器是否穿过驾驶舱、脚和地面。工具渲染与命中必须用同一轴线，不能靠动画遮挡掩盖。
5. **安全召唤质量**：优先有支撑且玩家可到达的候选点，解释召唤失败；不为了“一定成功”把机甲投到远处落差平台。
6. **测试效率**：在一个隔离进程内复用 fixture 和完整外观矩阵；只有程序集变更和读档用例必须重启。记录阶段耗时，区分工具/截图开销、世界生成时间和实际帧耗时；旧报告的约 17 ms p95 不能直接当作本轮性能结论。

下一轮建议先修战斗与安全退出，再补顶碰；美术继续以真实画面中“能辨认驾驶舱、腿和工具”为标准微调，而不是不断增加颜色和螺丝。
