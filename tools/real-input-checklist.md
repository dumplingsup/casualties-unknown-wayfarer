# 物理键盘/鼠标验收清单（桌面解锁后）

当前自动化环境是 Windows 锁定会话（LogonUI），不能用物理键鼠。以下步骤在用户解锁桌面后
运行；测试仍使用隔离副本和独立 userdata，不写正式存档。

1. 关闭任何测试游戏进程，确认 `CasualtiesUnknown` 不是正式安装目录的进程。
2. 用 `tools/launch_mech_test.ps1 -Run human-real-01 -Visible` 启动隔离副本。
3. 进入世界后，用物理 **G** 召唤、走近后 **F** 上机；确认 HUD/机甲/真实主角头脸。
4. 物理 **A/D** 移动，短按/长按 **Space**，松开；用第二台显示器或录制确认：
   - 长按持续喷气，松开后下落；
   - 顶碰时 HUD/喷焰显示 blocked 且不穿顶，按住 Space 横移离开后恢复。
5. 物理鼠标左/右键分别测试左右臂；检查瞄准端点与命中方向一致。
6. 物理 **F** 下机（地面和空中各一次；空中应有拒绝/安全提示），再 **F** 上机。
7. 物理 **P** 打开装配台：
   - 点选部件/翻页，观察实时预览；
   - 点 Apply；点 Cancel 验证草稿不写入；
   - 换至少一个新机体/新臂/新腿/新推进器/新喇叭。
8. 物理 **H** 测喇叭。
9. 存档：地面保存一次、高空（挖竖井后停在半空）保存一次；重启/读档，确认 loadout
   恢复、beacon 存在、无永久冻结或隐身。
10. 记录：输入指纹、DLL 哈希、运行目录、截图/录像、`Player.log`、`status.json`；
    将未通过项写入 `docs/WAYFARER-V0.4-TEST-REPORT.md` 的对应行。
